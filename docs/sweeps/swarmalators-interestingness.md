## Harness settings

128×128 grid, channel 0 (Density), 250 warmup steps, flux gap 6, coverage
threshold 0.05 (a rasterised 384-particle swarm is sparse).

**Channel 0, not channel 1.** The kernel also exposes Phase, which is where a
swarmalator's signature colour ring lives, but phase wraps: cells at 0.99 and
0.01 are neighbours on the circle and maximally distant to the linear metrics.
Density is the honest channel for this metric stack. The consequence is that
this sweep ranks the swarm's *shape*, not its phase organisation — which is half
of what distinguishes the shipped presets from each other.

## Reading

**No candidate beat the incumbent.** Static phase wave (0.636) edges the best
swept set (0.634), and the swept winner J=1, K=−0.1 is Splintered phase wave's
own parameter set — it reproduces that preset's score to three decimals, which is
a useful independent check that references and swept sets are scored identically.

The spread across the whole J/K plane is narrow: **24 of the 25 sets fall in
0.538–0.634**. Density alone cannot see most of what separates these
regimes, because they differ mainly in how phase is arranged over a swarm of
roughly the same shape. The one set that does separate clearly is J=1, K=1
(0.274): full synchronisation collapses the swarm into a single tight disc,
which the coverage term correctly reads as too small.

## Promotion

None. The best incumbent wins on the metric, and the metric can only see half of
