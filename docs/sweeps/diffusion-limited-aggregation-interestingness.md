## Harness settings

192×192 grid, channel 0 (Cluster), 500 warmup steps, flux gap 6, coverage
threshold 0.05.

**`seed: 7` is pinned on every set, and it is mandatory here.** DLA is the only
one of this stage's twelve kernels that falls back to `Math.random()` when no
seed param is supplied (`kernel.ts` line 231). Without a pinned seed the sweep
would not reproduce, which is the harness's core contract.

**Every set scores temporal flux exactly 0.0000, deliberately.** DLA has a
terminal state: once the cluster reaches the grid limit of the walker spawn
ring, walkers spawn on top of it and nothing further sticks. Warmup 500 puts
every set past that point, including the slow low-stickiness ones, so the
liveliness term is a constant 0.85 across the whole run and the ranking is a
pure comparison of final cluster morphology. A shorter warmup would have made
flux a measure of which sets had not finished growing yet, which is not a
property worth ranking.

## Reading

Stickiness dominates completely: **all five top-scoring sets have stickiness
0.15**, and the three shipped presets rank in exact reverse order of theirs
(0.4 → 0.397, 0.8 → 0.335, 1.0 → 0.328). The mechanism is well understood in the
DLA literature and visible in the field PNGs — at stickiness 1 a walker freezes
on the first cluster cell it touches, so the outermost tips screen everything
behind them and the cluster grows as sparse dendrites. At low stickiness a
walker bounces off the tips many times before committing, works its way into the
fjords, and fills them in. Lower stickiness makes a *denser* cluster, not a
looser one.

## Promotion: Dense coral, 0.397 → 0.542

```
{ walkersPerStep: 80, maxWalkSteps: 400, spawnRadius: 0.03, stickiness: 0.4,  seedCount: 3 }  →
{ walkersPerStep: 64, maxWalkSteps: 400, spawnRadius: 0.06, stickiness: 0.15, seedCount: 4 }
```

+0.145 (+36.5%), and it is not a coverage artefact — every component improves:
coverage 0.397 → 0.430, entropy 0.351 → 0.610, spatial autocorrelation 0.519 →
0.660. The identity is preserved and sharpened: this preset exists to show the
dense end of DLA, and low stickiness is the parameter that actually produces it.

`walkersPerStep` moves 80 → 64 as a side effect of the sweep pinning it there.
That knob sets how fast the cluster grows, not what the finished cluster looks
like, so promoting the measured set verbatim is the honest choice rather than
grafting the old rate onto new morphology.

Verified: re-running with the promoted params in the reference list reproduces
0.542 exactly.

**Branching and Multi-seed are left alone.** Both score low (0.328, 0.335), but
high stickiness is exactly what makes a branching dendrite, which is what
"Branching" is for — the same reasoning that kept the canonical Lorenz ρ=28 and
Clifford classic in place despite low scores. Replacing them would leave the
gallery with three variations on "dense".
