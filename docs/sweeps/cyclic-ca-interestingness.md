spirals or demons by ~150), flux gap 4, coverage threshold 0.5.

It sits at ~0.50 for every live regime, which is the point: it keeps
coverageFactor out of the way so structure and detail do the ranking.

## The finding: two of the three presets had frozen solid

Turbulence and Crystal lattice both score **temporal flux exactly 0.0000** and
spatial autocorrelation ≈0.03. For a cyclic CA — a model whose entire appeal is
rotating spiral waves — that is a dead sim: after ~150 steps the field has locked
into static, unstructured noise and nothing moves again. "Demons" was the only
shipped preset still turning.

The pattern across the sweep is consistent. Every set that freezes does so
because the threshold is too high for the number of states: at threshold ≥3 on
Moore, and at threshold ≥2 on von Neumann, too few cells ever accumulate enough
successor-state neighbours to advance, and the field jams.

## Promotion: Turbulence, 0.250 → 0.719

```
{ states: 8, threshold: 3, neighbourhood: "moore" }   →
{ states: 8, threshold: 2, neighbourhood: "moore" }
```

One parameter, +0.469 on the composite, and every supporting metric confirms it
is a defect fix rather than a metric preference: temporal flux 0.0000 → 0.1036
(it moves again), spatial autocorrelation 0.04 → 0.82 (it is organised rather
than noisy), entropy 0.60 → 0.59 (unchanged). The identity is preserved — same
eight states, same Moore neighbourhood, same turbulent character — and the
promoted set was independently the third-highest scorer of the whole run.

Verified: re-running the sweep with the promoted params in the reference list
reproduces 0.719 exactly.
